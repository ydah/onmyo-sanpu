# 陰陽算譜

凡陰陽算譜者、以九字記籌、以陰陽定其符、憑値於式神、以卦占斷吉凶、以反閇致往復、遂成算術之法也。

此卷所藏、陰陽算譜之處理系 `onmyo` 也。以椎十一造之。披 `.fu` 之符、析祭文爲字句、結字句爲樹、因其樹而修行法。

## 造作

```sh
make
```

## 修法

```sh
./onmyo examples/fizzbuzz.fu
./onmyo --tokens examples/fizzbuzz.fu
./onmyo --ast examples/kaijo.fu
```

無符者、即修祭文。加 `--tokens` 者、但出字句列、不修。加 `--ast` 者、但出構文樹、不修。

祟品第如左。

- `0`: 成就
- `1`: 修中祟
- `2`: 字句構文亂
- `3`: 入出力引數亂

## 境は語なり

陰陽算譜は括りの符を用ゐず、語を以て境とす。真言は `阿` に始まり `吽` に終はり、註は `註` より行末に至る。行法名は裸にて記す。

```text
阿ふぃず吽を唱へ 急急如律令
註 此は行末まで註なり
開白と申す行法、修するに
結願
```

式神名は十二天将、十干、十二支の三十四名に限る。

```text
貴人 螣蛇 朱雀 六合 勾陳 青龍 天空 白虎 太常 玄武 太陰 天后
甲 乙 丙 丁 戊 己 庚 辛 壬 癸
子 丑 寅 卯 辰 巳 午 未 申 酉 戌 亥
```

## 格支配

凡述語者、各有所取之格。格違則祟。

```text
甲に乙を生じ
甲より乙を剋し
甲に乙を乗じ
甲を乙にて祓ひ
甲は乙に勝り
```

単項受之以 `を`。述句・連鎖・呼出受之以 `これを`。複式を分かたんと欲せば、式神に憑かせて後に用ゐる。

```text
式神甲を喚び 臨に兵を生じ、これを憑かせしむ 急急如律令
甲に闘を乗じ、これを唱へ 急急如律令
```

## 界及反閇

結界者、張界而隔内外。式神召於現界、改自内及外、放自現界。占之枝及反閇之歩、各有新界。

```text
結界を張り
  式神甲を喚び 皆を憑かせしむ 急急如律令
結願

式神乙をして 臨 より 前 に至るまで 歩を 兵 とし 反閇せしむ
  反閇を止め 急急如律令
結願
```

入口行法、唯 `開白`。卦爲 `吉` `凶`、籌之負符爲 `陰`。陰陽は九字の直前に在る時のみ数の符となる。

## 試驗

```sh
make test
```

其試驗所驗、字句境、式神名、格支配、受、連鎖、界、反閇、歩制御、短絡、開白、移行祟、并 `--tokens`、`--ast` 起否也。

## 例符

- `examples/fizzbuzz.fu`: 自一至百唱之、占三五徴。
- `examples/kaijo.fu`: 遞修己法、献階乗。
- `examples/hibo.fu`: 以反閇唱斐波那契列。
- `examples/kekkai.fu`: 示結界之内外。
- `examples/henbai.fu`: 示歩及其止。

## 自 v1 移 v2 之法

先以移行具觀其差、而後書入。

```sh
tools/aratame.sh old.fu
tools/aratame.sh --write old.fu
```

既定値爲 dry-run。具唯機械可定之旧式自動改之、文脈を要する所には `註 要確認` を附す。詳細見 `docs/文法設計.md`。
